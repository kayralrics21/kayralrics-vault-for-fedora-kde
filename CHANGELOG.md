# Changelog

## v1.1 — Multi-select and bulk actions

- Multi-select in NOTES, FILES and TRASH with Ctrl/Shift and keyboard Ctrl+A.
- SELECT ALL, CLEAR and visible selected-item counts in all three views.
- Batch move to trash for notes and files; batch restore and permanent delete for mixed trash entries.
- Batch actions validate selections before committing, minimize encrypted index writes, and generate encrypted per-item activity logs plus batch summaries.
- Preserve multiple selected rows during list refresh and filtering.
- Added storage/GUI integration tests for multi-select, bulk operations, and keeping unselected notes safe.
